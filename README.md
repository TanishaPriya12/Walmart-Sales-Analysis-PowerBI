# Walmart Sales Analysis Dashboard

## Project Overview

This project is an end-to-end Sales Analysis Dashboard developed in Power BI using Walmart retail data. The dashboard provides insights into sales performance, product performance, customer behaviour, and business trends through interactive visualizations and KPI tracking.

---

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

---

## Dashboard Pages

### Executive Summary
- Business overview
- KPI Cards
- Overall sales performance
- Quick business insights

### Sales Analysis
- Sales trends over time
- Regional performance
- Category-wise analysis
- Profit and Discount analysis

### Product Analysis
- Top-selling products
- Product profitability
- Category and Sub-category performance
- Product comparison

### Customer Analysis
- Customer distribution
- Customer segments
- Customer purchasing behaviour
- Regional customer insights

### Business Insights & Recommendations
- Key business findings
- Sales improvement opportunities
- Product recommendations
- Customer growth recommendations

## Key KPIs

- Total Orders

- Average Discount
- Profit Margin %
